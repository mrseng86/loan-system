# Beauty Camera Pose Guide

一个手机网页拍照辅助工具，帮助用户通过构图线、姿势轮廓和参考图，拍出更自然、更好看的社交媒体照片。

## 项目介绍

这个项目不是普通相机 App，而是一个「拍照构图教练」。

用户打开手机浏览器后，可以开启相机，在实时画面上看到构图线、姿势参考和拍照引导，例如全身构图、半身构图、回眸姿势、亲子拍照、低机位显腿长等。

它的目标是帮助不会拍照的人，也能照着屏幕提示拍出更好的照片。

## 核心功能

- 手机浏览器开启相机
- 支持拍照预览
- 支持构图辅助线
- 支持姿势模板
- 支持上传参考图拍同款
- 支持调整参考图透明度
- 支持前后镜头切换
- 不需要后端和数据库

## 使用场景

- 女朋友叫男朋友帮忙拍照
- 父母帮孩子拍亲子照
- 旅行打卡拍照
- 小红书 / Instagram / Facebook 内容创作
- 美容院、服装店、婚纱店辅助客户拍照
- 活动 photo booth 拍照引导

## 项目定位

这是一个轻量级的网页相机工具，重点不是美颜滤镜，而是帮助用户解决「不会构图、不会摆姿势、不会拍同款」的问题。

未来可以继续加入 AI 人脸检测、构图评分、美颜滤镜、自动提醒脚被切掉、头部太高、人物太靠边等功能。
